# Homebrew tap

Homebrew formulae maintained by [frknue](https://github.com/frknue).

## shopify-auth

Install [`shopify-auth`](https://github.com/frknue/shopify-auth):

```sh
brew install frknue/tap/shopify-auth
```

`shopify-auth` requires Shopify CLI. Install it from Shopify's official tap if
needed:

```sh
brew install shopify/shopify/shopify-cli
```
